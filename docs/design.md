# 长征 不朽征途 代码与设计说明

作品围绕中央红军长征的历史事件、地理环境和人物经历组织内容。主要展示目标是让读者在图文展览中建立事件先后关系，并理解地形、运输和补给对行军的影响。

## 结构与内容边界

`src/main.tsx` 负责应用入口、章节导航、路线状态和地图操作。`src/home-route.tsx` 提供首页地图和章节入口，`src/people.tsx` 提供人物选择，`src/spirit-film.tsx` 提供随自然滚动切换的长征精神场景。

事件与行军正文分开维护在 `src/narrative-data.ts`，四次渡河的数据位于 `src/crossings.ts`，人物与精神内容分别位于 `src/people-stories.ts`、`src/spirit-film-data.ts`。1934—1935 年中央红军主线与 1936 年主力会师分开说明，避免将不同队伍的历程连接为一条行军线。

## 自行编写的界面样式

所有页面布局、颜色、排版、控件外观和断点规则均保存在项目 CSS 文件中。`src/exhibition-base.css` 仅为本展实际使用的标题、段落、列表、图片和按钮设置浏览器基础表现，其后由各章节样式定义最终视觉效果。

`src/style.css` 承担主体样式，`src/hero-artwork.css`、`src/spirit-film.css`、`src/cartography.css`、`src/editorial.css` 分别服务于封面、精神场景、地图和背景阅读。页面不依赖第三方 UI 组件或样式框架。

## 地图与转场

`src/route-geometry.ts` 将经纬度参考点映射到 SVG 坐标，生成节点间的概化曲线与笔迹外观。`src/cartography.tsx` 绘制底图和路线，`src/main.tsx` 组织站点选择、缩放、拖动及复位。赤水局部图分别标出四次渡河的渡口、方向与说明；地图不是精确复原的历史测绘图。

章节状态使用 URL hash。`src/chapter-motion.tsx` 处理章节切换、焦点和滚动位置；支持时使用浏览器 View Transitions API，其余情况使用渐隐过渡。`src/shared-photo.ts` 负责测量图片边界、计算共享图像转场和中断清理，GSAP 只提供时间线与数值插值能力。Framer Motion 用于声明式动画及滚动进度，未将其底层动画算法列为自主实现内容。

## 本地运行与资源

Vite 的生产构建将应用生成为经典脚本，所有成品资源使用相对地址。`public/intro.js` 在应用准备时显示开场并处理跳过、加载等待及失败重试。图片和字体不依赖外部在线请求；`src/station-media.ts` 只预热已访问或悬停的少量站点图片。

`src/soundtrack.ts` 使用本地经典脚本片段组合音频，兼容直接打开本地文件的环境。音乐由页面提供暂停与恢复操作，并保留用户手动暂停的选择。图片使用 WebP，高清替换记录写入 `docs/image-updates.json`；替换不会生成或补画历史人物及场景。

## 可用性与验证

保留语义化标题、图片替代文本、导航标签、按钮状态及可见键盘焦点。人物和渡河标签支持方向键切换，地图地点支持 Enter 和空格，系统减少动态效果设置会减少动画而保留内容及操作。

回归检查包括四种屏宽下的六章导航、十个路线站点、四次渡河切换、地图缩放复位、六个人物切换、本地资源加载和页面横向溢出。实际浏览器版本、构建结果与检查范围以 `docs/verification.json` 为准。移动端的详细触控模拟结果保存在 `docs/mobile-verification.json`。


## 移动端布局与交互

`src/mobile.css` 的规则限定于 720 像素及以下，`src/mobile-experience.tsx` 通过媒体查询同步小屏状态、提供正文定位与历史目录。桌面保持原有组件排布和样式。历史背景使用 CSS 重新安排导语、主图、正文与补充图片；路线将行军形势说明置于正文之后，并以原生下拉框代替占据大量空间的完整站点目录。

选站后同步路线 hash，并将正文放到固定导航栏下方；阅读区提供返回地图和前后站操作。四次渡河保留图解与文字，使用明确入口在两者间定位。顶部章节栏可横向滑动并保持当前章节可见；历史章节提供随阅读保持可见的十节点目录。人物信息保持完整，调整窄屏排版并提供返回选择入口。

小屏保留桌面展览的绘画、配色、书法和转场风格。长征精神只加载当前布局所需的图片，小屏按段落展示图片，桌面保留原有背景切换。媒体查询变化时两种布局可重新切换，系统减少动态效果设置仍然有效。所有新增界面与交互均使用项目自写 CSS、原生控件和已申报的 React 能力，没有新增第三方样式库或组件库。
