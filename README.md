# 长征 · 不朽征途

以中央红军1934—1935年行军为主线的数字历史展览，接续介绍1936年三大主力会师。保留六个独立章节： 首页、历史背景、重要历史、征途路线、长征精神、征途群像。

## 直接打开

下载并解压整个仓库，双击 **打开长征展览.html**。也可以直接打开 **dist/index.html**。请保留 dist 的完整目录结构，图片、地图、字体和配乐均为本地文件，无需启动命令文件。

建议使用当前版本的 Edge 或 Chrome。配乐默认静音，点击导航栏的播放按钮开启。

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| 打开长征展览.html | 供日常双击打开的成品入口 |
| dist/ | 已构建成品，可整体用于静态部署 |
| dist/index.html | 成品网页的实际入口，不能删除 |
| index.html | Vite 开发与构建入口，不能删除 |
| src/ | 当前版本的 React、TypeScript、样式和展览数据 |
| public/ | 本地图片、地形、配乐、开场文件与素材许可记录 |
| docs/ | 图像资料记录和最终验收记录，不在网页中展示 |
| scripts/ | 本地字体字形维护工具 |
| package.json、package-lock.json | 开发依赖与构建命令 |
| node_modules/ | 本机开发依赖，由 npm 安装，不上传 GitHub |

两份 index.html 分别用于开发构建和成品运行。只有中文入口是快捷跳转文件；删除 dist/index.html 会使成品无法打开，删除根目录 index.html 会使项目无法正常构建。

## 开发与构建

需要 Node.js 及 npm。

```sh
npm ci
npm run dev
```

生成成品：

```sh
npm run build
```

构建包含 TypeScript 检查，输出至 dist。静态网站服务直接使用 dist 目录。成品以经典脚本加载，可在本地 file 地址下运行。

## 当前展览

- 首页使用现成油画与无人物的山峰云雪裁切区统一构图；左侧书法标题、右侧行军队伍。鼠标背景位移最大水平4px、垂直2.5px，停下即停止，手机和减少动态效果模式保持静止。
- 重要历史包含十个事件；点击事件名称进入对应路线讲解，保留大图进入小图的共享图片转场。
- 路线提供十站选择、键盘操作、地图缩放、全线复位及赤水四步局部讲解。中央红军行军主线到1935年吴起镇，1936年会宁、将台堡另列。
- 事件及路线正文采用连续段落，按战况、地理、运输补给和行军组织展开。
- 长征精神保留六组图文场景；征途群像保留六位人物，毛泽东居首。
- 页面不显示史料出处、素材作者年代或来源链接。原图中的金色画框已按画面边界裁除，无生成式补画。
- 保留桌面与手机布局、真实可选文字和减少动态效果支持。字体、地图与图片均无需在线请求。

## 内容与素材维护

正文主要在 src/narrative-data.ts、src/exhibit-notes.ts、src/crossings.ts、src/spirit-film-data.ts 和 src/people-stories.ts 维护。地图坐标与路线在 src/route-geometry.ts。

素材、字体和地图数据的许可与出处记录保存在 public/fonts、public/media 和 docs，供维护及核对使用。来源链接不代表开放授权，第三方作品权利仍归原权利人。网页使用的标题字体为本地 WOFF2 子集；scripts 中保留了从官方字体原文件扩充字形的工具。

本地仅保留当前版本，旧备份、重复入口和未使用的旧交互文件已清理。GitHub 仓库的 main 分支包含当前源代码和构建好的 dist。
