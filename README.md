# 长征 · 不朽征途

武汉大学 2026 年零杯网页设计大赛主题三「长征万里，薪火千秋」。这是一个以展览阅读为主的独立网页项目。源代码与排版为本版重新编写。

## 运行

- 本地打开成品：解压完整压缩包后，双击「打开长征展览.html」，也可直接打开 dist/index.html。展览页面和图片无需命令行、npm 或联网；外部史料链接需要联网。
- 源码开发：在项目目录运行 `npm ci`、`npm run dev`。
- 生产构建：`npm run build`。在静态 HTTP 服务上提供 dist 即可。
- 目标浏览器 Chrome 129 及以上。布局适应 1920、1440、720 像素及手机窄屏。首页使用静态艺术作品；移动端与减少动态效果模式保留全部地图入口，减少动态效果模式不播放滚动缩放。

## 史料与素材

路线章正文依据各站史料编写，对应来源记录在 src/exhibit-notes.ts。地图使用 [Natural Earth 公有领域河流数据](https://www.naturalearthdata.com/about/terms-of-use/) 和关键地点近似经纬度。地形阴影和等高线基于 Mapzen Terrain Tiles 的高程数据，已重投影并随站离线分发。高程数据包括 SRTM 等来源，见 [Mapzen 署名说明](https://www.mapzen.com/rights/)。红线按历史先后连接节点，省略实际绕行。地图不用于测绘。

- 首屏使用艾中信油画《红军过雪山》（1957）的数字图像，画面为艺术作品，显示时作局部裁切；来源与作者可从首屏右下角打开。
- 图片选择顺序为：可核实的历史图像（含亲历者速写）、后世艺术作品、对应实地照片，最后才考虑 AI。此版本所有展示图均已替换为前三类，原有 20 个未使用的 AI 图片与视频文件已从素材目录移除。
- “重要历史”使用黄镇《星夜渡过雩都河》《泸定桥》亲历者速写、1936 年干部合影、与各节点相对应的五幅油画及吴起胜利山纪念雕塑实拍。艺术作品与历史照片分开标注。合影发生在甘肃宫和镇，不冒称会宁会师当场照片。
- 配图逐项元数据见 `src/exhibits.ts`；原作作者、来源、类型同时显示于图片说明，可点击来源或放大图片。现有照片的开放许可仍按原署名执行；新引入艺术作品和刊载图片没有统一开放许可，版权归原权利人，来源链接不等同于授权。
- 第三部分保留“进入路线详解”，继续进入第四部分的地图及史料正文。
- 档案及现址照片的署名、来源和许可位于图片说明。长征纪念浮雕照片由 Xiquinho Silva 拍摄，采用 CC BY 4.0，本站进行了缩放、WebP 编码和显示裁切。
- 历史背景使用 Zhangzhugang 拍摄的于都东门渡口现址照片（2014，CC BY-SA 3.0）、1930 年代红军资料照片和 Xiquinho Silva 拍摄的纪念浮雕实拍。浮雕与现址照片均按实际素材性质标注。
- 赤水局部图的地形使用 Mapzen 高程数据计算晕渲，河道使用 OpenStreetMap 实际几何数据。渡口为地名近似定位，短箭头仅表达有史料依据的渡河方向。现代地形与河道作为地理参照，不代表对 1935 年河岸、浮桥与行军轨迹的精确复原。
- 新增图片和地理数据的来源及授权在 `public/media/realism-attribution.txt`，ODbL 地理数据随 `public/media/chishui-map-data.json` 提供。
- 毛泽东照片为 1937 年埃德加·斯诺拍摄，文件页标注 CC0。周恩来照片为 1937 年 12 月，作者不详，文件页标注 PD-China。长征时期红军影像作者不详，文件页标注 PD-China。

## 首页路线图与跳转

- 保留原首页标题、配色和导航，向下滚动进入路线图。地图与第四部分复用 `src/route-geometry.ts`，避免节点坐标各自维护造成偏差。
- 根据提供的 Apple 网页参考视频实现滚动缩放、文字上移与路线描绘；根据博物馆参考视频实现错落展板入场。代码独立实现，无参考页面代码复制。
- 首页地图节点以及下方十站目录均以真实锚链接指向第三部分 `#events-1` 至 `#events-10`。点击后聚焦对应标题；刷新、直接打开链接、浏览器前进后退均保留地点。每站提供返回首页地图入口。
- 九个节点表示中央红军 1934—1935 年行军主线，会宁和将台堡用虚线圆圈单独标记 1936 年会师地，不与吴起连接成一条行军线。地图为历史节点示意，不是精确行军轨迹。
- 430 像素以下地图可横向滑动，下面的文字目录完整保留。图片与字体随包提供，无在线地图 SDK、图片热链或新增运行时依赖。

## 开场 loading

- 开场沿用首页的朱红书法、暗色山川轮廓与暖金细线；「长征」揭示后，一段红色征途依页面、字体和首页油画的准备状态向前延伸，再淡入原首页。开场文字引用毛泽东《七律·长征》首联。
- 原生 HTML、`public/intro.css` 与 `public/intro.js` 在 React 主包之前显示，避免下载主包期间白屏。开场与首页共用标题字体，WOFF2 以内嵌数据提供，兼容离线入口；不新增第三方库或图片。
- 正常首页开场至少保留约 1.4 秒，退场约 0.65 秒。提供「跳过开场」；脚本尚未准备好时，点击会记住跳过意图，正文准备好立即进入。站内章节切换不重复播放。
- 只等待关键资源，不等待所有展图、地图或音乐。正文已可用时，图片或字体最多再等待 5 秒；失败也会放行。主包超过 6.5 秒仍未准备好时，显示慢网提示及重新载入入口。开场脚本自身失败时，正文仍可正常进入。
- 支持手机、横屏、键盘及屏幕阅读器。开场期间正文不可误触，退场后恢复滚动和交互；减少动态效果模式取消动画及人为停留，直接章节链接不强制等待首页图片，也不增加开场停留时间。
