# 长征 不朽征途

本作品是一座可离线浏览的数字历史展览，以中央红军 1934—1935 年行军为主线，接续介绍 1936 年三大主力会师，通过历史事件、山川路线与人物事迹呈现长征历程。

## 运行方式

解压完整作品文件夹，双击根目录的 **打开长征展览.html**，或使用浏览器打开 **dist/index.html**。无需安装依赖、启动服务器、登录账号或连接网络。

请保留 `dist` 目录结构。地图、图片、字体、开场和配乐均随成品提供；不能单独拷贝一个 HTML 文件运行。

- 目标浏览器：Chrome 129，构建目标设置为 `chrome129`。
- 主展示规格：1440 × 900 像素；布局同时支持 1920、720 和手机宽度。
- 实际回归环境：Microsoft Edge 157.0.4341.42；桌面检查规格为 1920 × 1080、1440 × 900；移动端采用浏览器触控模拟，检查 320、360、390、430、600、720 像素宽度及 844 × 390 横屏。目标版本 Chrome 129 尚未单独实测。
- 支持减少动态效果设置；开启后保留导航和全部内容，减少转场及视差。
- 配乐会尝试自动播放；浏览器拦截时，在首次有效点击或按键后播放。导航栏可暂停和恢复，手动暂停后切换章节不会重新播放。

## 内容与操作

| 章节 | 内容与操作 |
| --- | --- |
| 首页 | 主题封面、可点击路线地图、十个地点目录和五个章节入口 |
| 历史背景 | 战略转移背景、于都集结与渡河、不同红军队伍的长征概况 |
| 重要历史 | 十个事件的图文解读；点击事件标题进入对应路线站点 |
| 征途路线 | 十站选择、上一站与下一站、地图放大缩小、拖动和复位；四渡赤水提供四步渡河图解 |
| 长征精神 | 六组图文场景，以具体事迹解释精神内涵 |
| 征途群像 | 六位人物的事迹切换与完整阅读 |

地图中的路线是关键节点之间的概化示意，不表示逐段实测行军轨迹。1935 年吴起镇为中央红军行军主线终点，1936 年会宁、将台堡另列为主力会师地点。

人物选择和四渡赤水标签支持左右方向键、Home、End；地图地点支持 Enter 和空格，其他导航与按钮支持常规键盘操作。浏览器前进、后退可用于章节导航。

## 移动端响应式适配

本作品提供移动端响应式版本。720 像素及以下启用专门的小屏阅读与触控布局，与桌面版共用六章内容、路线和人物数据，保留地图、四渡赤水图解、共享图像转场及配乐功能。

- 首页保留油画与书法风格，重新编排标题和导语，提供“开始观展”入口；章节导航可横向滑动，并自动显示当前章节。
- 历史背景按导语、主图、正文、补充图片组织，避免连续图片遮挡核心内容。
- 重要历史提供随阅读保持可见的十节点目录；路线提供紧凑选站、选站后正文定位、上下站切换及返回地图，刷新后保留所选站点。
- 地图保留触控拖动、缩放与复位；四次渡河可逐步切换并就近阅读说明；人物章节提供六人切换及返回选择入口。
- 针对窄屏调整字号、行距、标题换行和控件间距；长征精神按段落加载移动端配图，减少隐藏桌面画面的渲染。

已完成六档小屏触控模拟、横屏、正常动画和减少动态效果检查。1440 与 1920 像素桌面六章的元素位置及计算样式与优化前一致。实际记录见 [移动端验证说明](docs/mobile-verification.json)。

## 设计与实现

以书法标题、历史绘画、地形底图及暗红和土金色构成展览风格。历史事件侧重战局与影响，路线正文侧重地形、渡口、运输和补给，人物章节补充具体经历，形成相互关联的阅读入口。

页面布局、颜色、排版、按钮和响应式规则均由项目 CSS 编写，没有引入预设样式库或成套 UI 组件库。地图使用项目内的 SVG 地点、路线几何与状态逻辑；地图及历史内容数据随项目保存。项目采用静态前端，没有后台服务、数据库或用户数据采集。

详细的结构、交互实现与第三方能力边界见 [代码与设计说明](docs/design.md)。

## 源码开发与构建

开发环境需要 Node.js 20.19 及以上版本和 npm；仅浏览成品时不需要安装这些工具。

```sh
npm ci
npm run dev
```

生成可提交成品：

```sh
npm run build
```

构建先执行 TypeScript 检查，再生成 `dist`。生产入口使用经典脚本及相对资源路径，以支持直接从本地文件打开。

## 文件结构

| 路径 | 用途 |
| --- | --- |
| 打开长征展览.html | 成品快捷入口 |
| dist/ | 可直接打开或部署的完整成品 |
| src/ | React 组件、项目自写 CSS、地图及叙事数据 |
| public/ | 图片、字体、开场、音频与素材说明 |
| docs/design.md | 代码与设计说明 |
| docs/verification.json、docs/mobile-verification.json | 构建、桌面比对与移动端触控检查记录 |
| scripts/ | 字体维护和比赛提交包生成工具 |
| package.json、package-lock.json | 依赖声明、版本锁定及构建命令 |

`node_modules`、Git 元数据、备份和本地检查截图不属于参赛成品。开发入口 `index.html` 和成品入口 `dist/index.html` 各有用途，均应保留。
